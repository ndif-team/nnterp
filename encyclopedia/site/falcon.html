Falcon

A parallel block on every checkpoint but Falcon-RW: the block adds the attention's output into the MLP's output tensor in place, so mlp_output is a copy taken as the MLP returns.

The Notes

03 · what to know before you run

On 7B and 11B one LayerNorm feeds both sublayers

h   = input_layernorm(x)
m   = mlp(h)
m  += self_attn(h)          # in place, into the MLP's output tensor
out = m + x

input_layernorm is the block's only norm. Its output tensor is passed to the attention and then to the MLP, so self_attn.input and mlp.input are the same tensor: an in-place edit of self_attn.input reaches the MLP too, and an assignment replaces only the attention's argument. The MLP never reads its own block's attention: the first MLP that reads block i's attention is block i + 1's. ffn_hidden_size is the MLP's width, which nnterp serves as intermediate_size.

mlp_output is a copy, and the live tensor is not the MLP's

The block adds the attention's output into the MLP's output tensor in place, so once the block has run, mlp.output holds mlp + attn. mlp_output is a copy taken as the MLP returns and holds the MLP's contribution alone. nnterp hands an edit of the copy back to the model, so an in-place edit and an assignment both land.

with model.trace(prompt):
    attn = model.layers[1].self_attn.attention_output.save()
    mlp = model.layers[1].mlp.mlp_output.save()
    live = model.layers[1].mlp.output.save()

assert torch.equal(live, mlp + attn)            # the live tensor after the in-place add

The block's own order is (mlp + attn) + x, so that sum reproduces layer_output bit for bit; x + attn + mlp differs from it by rounding in bfloat16.

with model.trace(prompt):
    x = model.layers[1].input.save()
    attn = model.layers[1].self_attn.attention_output.save()
    mlp = model.layers[1].mlp.mlp_output.save()
    out = model.layers[1].layer_output.save()

assert torch.equal((mlp + attn) + x, out)

One key/value head on 7B, eight broadcast on 11B

query_key_value is one Linear with no bias. On 7B (multi_query) its output is every head's query, then one key, then one value: view(batch, seq, num_heads + 2, head_dim), whose last two heads are the key and the value. attention_keys and attention_values have one head, [batch, 1, seq, 64], and an edit to either reaches all 71 query heads.

11B groups the output by key/value head, [q × 4 | k | v] for each of 8 groups. The attention copies each key and value to its four query heads before the rotary, so attention_keys and attention_values are num_heads (32) wide while model.num_kv_heads is 8. An edit to one of the four copies reaches only that query head.

attn = model.layers[1].self_attn
with model.trace(prompt):
    h = model.layers[1].input_layernorm.output.save()
    v = attn.attention_values.save()

fused = h @ attn.query_key_value.weight.T
rows = fused.view(*fused.shape[:2], model.num_heads + 2, model.head_dim)    # the 7B layout
torch.testing.assert_close(rows[:, :, -1:].transpose(1, 2), v)

Without ALiBi, read the values before the queries and keys

The attention does its own arithmetic. On the rotary checkpoints the queries and keys are the two returns of the rotary embedding, and the values are bound before it, so inside one trace read attention_values first. Asking for the queries or keys first raises OutOfOrderError naming value_layer_0.

attn = model.layers[1].self_attn
with model.trace(prompt):
    v = attn.attention_values.save()       # binds first
    q = attn.attention_queries.save()
    k = attn.attention_keys.save()

Rotary turns the whole head in rotate_half pairs, with rope_theta 10000 on 7B and 500042 on 11B. The pattern is the softmax's output (no dropout follows it), and the head outputs are the pattern @ values product, heads first in the forward and served [batch, seq, num_heads, head_dim].

The interior needs an eager load

transformers' FalconAttention runs sdpa unless told otherwise, and then neither scores nor pattern exist: the six interior values carry ⚠ and report load with attn_implementation='eager'. attention_output and mlp_output do not depend on the implementation.

model = StandardizedTransformer("tiiuae/falcon-7b", attn_implementation="eager")

Two more layouts load as FalconForCausalLM

  • Falcon-40B and Falcon-180B (new_decoder_architecture, two norms in parallel) give each sublayer its own LayerNorm of the block input, ln_attn and ln_mlp; neither has a standard name. The fused projection and the broadcast keys and values are 11B's, with 16 query heads per key/value head on 40B.
  • Falcon-RW (tiiuae/falcon-rw-1b, falcon-rw-7b) is sequential, with input_layernorm and post_attention_layernorm, biased projections, and ALiBi in place of rotary. Its fused projection is laid out by head, [q_h | k_h | v_h]. With ALiBi the read order is the forward's: queries, then keys, then values; values first raises OutOfOrderError naming query_layer_0.
  • On an ALiBi checkpoint the eager attention adds the bias twice: transformers builds it into the attention mask and adds it again to the scores, so attention_scores is q @ kᵀ / sqrt(head_dim) + 2 * slope_h * j / sqrt(head_dim) for key position j, plus the causal mask. Head h's slope is 2 ** (-8 * (h + 1) / num_heads), and transformers computes slope_h * j in bfloat16 on every load. The default sdpa load adds the bias once. On falcon-rw-1b in float32 the two loads' logits differ by up to about 1.5 on a sample prompt, so an eager trace there runs a different model from the default one.

quirks

Parallel block

Attention and MLP both read the block's input, through one shared norm or one each, and the block returns x + attn + mlp.

LayerNorm

Every norm is a LayerNorm: it subtracts the mean before scaling, so adding a multiple of the all-ones vector to the stream changes nothing that the next sublayer or the logits see.

Multi-query attention

One key/value head serves every query head (num_kv_heads is 1), so an edit to its keys or values reaches all of them.

quirks

Parallel block

Attention and MLP both read the block's input, through one shared norm or one each, and the block returns x + attn + mlp.

LayerNorm

Every norm is a LayerNorm: it subtracts the mean before scaling, so adding a multiple of the all-ones vector to the stream changes nothing that the next sublayer or the logits see.

Grouped-query attention

Several query heads share each key/value head (num_kv_heads is below num_heads), so an edit to one key/value head reaches every query head in its group. On most families attention_keys and attention_values are served before the repeat, num_kv_heads wide; the notes say where a family expands them first.

quirks

Biased q, k, v

The query, key and value projections carry a bias, so each is W·x + b.

LayerNorm

Every norm is a LayerNorm: it subtracts the mean before scaling, so adding a multiple of the all-ones vector to the stream changes nothing that the next sublayer or the logits see.

ALiBi

No rotary: a per-head bias, linear in the key's position, is added to the attention scores, so queries and keys carry no position and attention_scores includes the bias.

From the family module

04 · nnterp/families/falcon.py

Falcon (FalconForCausalLM): the 7B layout (parallel attention), with or without alibi, and the 40B layout.

transformer.{word_embeddings, h[i].{input_layernorm, self_attention, mlp}, ln_f} and lm_head. One norm feeds both sublayers and the block sums x + attn + mlp, but it does so by adding the attention output into the MLP's output tensor in place, so mlp_output reads a copy taken as the MLP returns, and a transform carries edits to it back into the model.

The attention does its own arithmetic, and config.alibi picks one of two branches of it with different operations, so each interior value names its operation by that flag. Without alibi the queries and keys leave apply_rotary_pos_emb and the pattern is the first softmax, which has no dropout after it; with alibi there is no rotary, the pattern is the dropout after the second softmax, and the head outputs are flattened over batch and heads. The 40B layout (ln_attn / ln_mlp, new_decoder_architecture) runs the same forward with its key/value heads already broadcast. falcon-11B has the 40B layout with num_ln_in_parallel_attn 1: one input_layernorm feeds both sublayers, and 8 key/value heads serve its 32 query heads.
