        (conv1d): Conv1d(10240, 10240, kernel_size=(4,), stride=(1,), padding=(3,), groups=10240)
        (in_proj): Linear(in_features=4096, out_features=18560, bias=False)
        (norm): MambaRMSNormGated()
        (out_proj): Linear(in_features=8192, out_features=4096, bias=False)
        (attention_queries) -> SSDQueries [batch seq groups state_dim]: C, the queries reading the state
        (attention_keys) -> SSDKeys [batch seq groups state_dim]: B, the keys writing into the state
        (attention_values) -> SSDValues [batch seq heads head_dim]: x, the values written into the state
        (betas) -> Gates [batch seq heads]: dt, the per-token write strength into the state
        (decays) -> Gates [batch seq heads]: A * dt, the per-token log decay of the state
        (state_input) -> State | None [batch heads key_dim value_dim]: The state entering the layer, or None at the start of a prompt (a copy of the cache's buffer)
        (attention_head_outputs) -> SSDHeadOutputs [batch seq heads head_dim]: y, the per-head outputs before the gated norm and the output projection
        (state_output) -> State [batch heads key_dim value_dim]: The state leaving the layer
        (states) -> States [batch seq heads key_dim value_dim]: The state after every token of this call; needs nnterp.chunk_per_token(model)
        (state): Unavailable: the chunk scan computes every token's state in one tensor per call, not one occurrence per token to walk with tracer.iter; read states, or state_after(t), after nnterp.chunk_per_token(model)
        (set_state_after): Unavailable: the chunk scan computes every boundary state in one cumulative step from the initial state, so a state written at token t does not flow into later tokens' states; assign state_input to change where a call starts
        (attention_output) -> Residual [batch seq hidden_size]: What the mixer adds to the residual stream
      )
      (attention_norm_output) -> Residual [batch seq hidden_size]: The normed stream entering the attention
      (layer_mid): Unavailable: a state-space block: one sublayer, the mixer, so there is no stream between sublayers and no MLP
      (layer_input) -> Residual [batch seq hidden_size]: The residual stream entering the block
      (mlp_norm_output) -> Residual [batch seq hidden_size]: The normed stream entering the MLP
      (mlp_input) -> Residual [batch seq hidden_size]: What the MLP is called with
      (layer_output) -> Residual [batch seq hidden_size]: The residual stream leaving the block, a tensor even when the block returns a tuple
    )
  )
  (norm): Mamba2RMSNorm()
  (logits) -> Logits [batch seq vocab_size]: The logits the model returns, after anything it does past lm_head (a softcap, a scale)
  (token_embeddings) -> Residual [batch seq hidden_size]: The embedding module's output; layers[0].input is what enters the first block
  (final_norm_output) -> Residual [batch seq hidden_size]: The residual stream after the final norm, what lm_head reads
  (lm_head_output) -> Logits [batch seq vocab_size]: The head's logits before anything the model does past lm_head (a softcap, a scale)
  (next_token_probs) -> NextTokenProbs [batch vocab_size]: The next-token distribution at the last position; derived, read-only
  (input_ids) -> Tokens [batch seq]: The token ids the model was called with
  (attention_mask) -> Tokens [batch seq]: The attention mask the model was called with; zeros are padding

The Notes

03 · what to know before you run

A gated norm over every head follows attention_head_outputs

out = h + mixer(norm(h))
mixer: y = ssd(x, dt, A, B, C) + D * x       # x: attention_values; y: attention_head_outputs
       return out_proj(norm(y * silu(z)))    # one norm over the mixer's whole width

The mixer gates y with silu(z) and then normalizes it over all heads together, whatever n_groups is. A head's term in attention_output depends on every other head, so zeroing one head of attention_head_outputs rescales the rest.

C and B are shared by the heads of a group

attention_queries (C) and attention_keys (B) have one row per group of heads, and the 130m to 2.7b checkpoints have one group, so an edit to either reaches every head. Mamba-Codestral has eight groups.

The pattern is rebuilt from the scan's values

There is no attention_probabilities. Per head the scan is a causal linear map over tokens, and the served values give its weights exactly:

y_t        = sum_s alpha[t, s] * x_s + D * x_t
alpha[t, s] = (C_t . B_s) * exp(decays_{s+1} + ... + decays_t) * betas_s

Repeat C and B from groups to heads first.

quirks

State space (Mamba-2)

The recurrent mixer is Mamba-2's SSD state-space scan, run in chunks over a prompt; nnterp serves its C, B and x as attention_queries, attention_keys and attention_values.

One sublayer per block

Each block is one norm and one sublayer, so it adds one contribution to the stream.

From the family module

04 · nnterp/families/mamba2.py

Mamba-2 (Mamba2ForCausalLM).

A pure state-space model: no attention and no MLP. The tree::

backbone.embeddings
backbone.layers[i]       Mamba2Block
    .norm                RMSNorm, the block's only norm
    .mixer               Mamba2Mixer, an SSD mixer
backbone.norm_f
lm_head

Each block is hidden + mixer(norm(hidden)) (the residual in float32 when residual_in_fp32), so the block's one contribution is the mixer's output and layer.input + linear_attn.attention_output == layer_output. The mixer is nnterp.StateSpace under the standard name linear_attn (the recurrent mixer's name on every hybrid). The block's norm keeps its name: a "norm" key would also match the mixer's own gated norm, and its output is linear_attn.input. There is no self_attn and no mlp, so support lists neither.

The sizes are the mixer's: num_heads and head_dim are the SSD heads (config.num_heads, config.head_dim), and intermediate_size is the mixer's inner width, expand * hidden_size, what in_proj expands to and out_proj reads from (the model has no MLP). With residual_in_fp32 the residual stream is float32 whatever the weights are, and the model casts it to lm_head's dtype and its logits to float32, so project_on_vocab is the family's own.
